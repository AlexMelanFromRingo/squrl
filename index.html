Why the link is not in a database

A shortener stores your URL and hands you a receipt. squrl compresses the URL into the link, so nothing expires, the same address always gives the same link, and anyone running this code can expand one — offline.

Where the bits go

Two schemes are worth having, so https:// is one bit — and once the model knows most links use it, that bit costs about a twentieth of one. Hostnames come from a dictionary, path words from another. What is left is the genuinely random part, and that is all the ruler is really measuring.

Opening one still needs a hop

A phone camera reads URLs; it cannot decompress one. Something has to turn the payload back into an address — this page, served for any path by the same static hosting, or the redirector in server/. Neither stores anything.
